# 보안 점검표 (리뷰 필수 항목)

| # | 점검 항목 | 기준 |
|---|---|---|
| S1 | 관리자 API 인증 | `/admin/**` 는 항상 `require_admin` 의존성을 거친다 |
| S2 | SQL 인젝션 | 문자열 연결 SQL 금지, 파라미터 바인딩만 사용 |
| S3 | 개인정보 로그 금지 | 이름·이메일·전화번호 등을 로그/감사 로그에 기록하지 않는다 (고객 ID만) |
| S4 | **자유 입력 텍스트** | 사유·메모 등 자유 입력은 길이 제한(예: 200자)과 공백 정리를 하고, 접근 로그에 원문을 남기지 않는다 |
| S5 | 입력 검증 | 금액은 양의 정수, 문자열은 최대 길이를 스키마에서 강제한다 |
| S6 | 시크릿 | 토큰·비밀번호를 코드/문서/로그에 하드코딩하지 않는다 (데모용 토큰은 예외로 표시) |
| S7 | 권한 변경 | 관리자 권한/승인 규칙을 완화하는 변경은 반드시 별도 승인 대상으로 표시한다 |
