# 변경 요청서 CR-2026-014 — VIP 환불 정책 개선 및 고액 환불 통제 강화

| 항목 | 내용 |
|---|---|
| 요청 부서 / 요청자 | 고객경험(CX)팀 / 김현업 팀장 |
| 요청일 / 희망 적용일 | 2026-10-16 / 2026-11-02 |
| 우선순위 | 높음 (감사 지적사항 포함) |

## 1. 배경
- 최근 3개월간 VIP 고객의 "환불 기간이 짧다"는 불만이 증가했습니다. (VIP 이탈 방지 필요)
- 환불 사유를 기록하지 않아 **환불 원인 분석이 불가능**합니다.
- 고액 환불에 대한 **내부 승인 절차가 없다**는 내부 감사 지적을 받았습니다.

## 2. 요구사항
| ID | 요구사항 |
|---|---|
| R1 | VIP 고객의 환불 가능 기간을 구매일로부터 **60일**로 연장한다. (일반 고객은 현행 30일 유지) |
| R2 | 환불 요청 시 **환불 사유**를 필수 입력으로 한다. (원인 분석·감사 목적) |
| R3 | 환불 금액이 **1,000,000원을 초과**하는 건은 자동 승인하지 않고 **관리자 승인 대기** 상태로 접수한다. |
| R4 | 고객 화면, 안내 이메일, 환불 정책 문서의 관련 문구를 위 정책에 맞게 변경한다. |

## 3. 제약 조건
- 기존 고객·주문·환불 데이터는 **손실 없이 유지**하고, **서비스 중단 없이** 반영해야 합니다.
- 모바일 앱(구버전 포함)에 미치는 영향이 있으면 **사전에 알려주세요.**
- 변경 근거와 승인 이력은 감사 대응을 위해 **추적 가능**해야 합니다.

## 4. 현업 인수 기준 (이렇게 되면 완료)
1. VIP 고객의 구매 45일 경과 주문은 환불 접수가 가능하고, 일반 고객의 45일 경과 주문은 불가하다.
2. 환불 사유 없이 접수하는 경우 사용자에게 입력 안내가 표시된다. (적용 방식은 IT와 협의)
3. 1,000,000원 초과 환불은 관리자 콘솔의 '승인 대기' 목록에 나타나고, 승인 전에는 환불되지 않는다.
4. 고객 화면·이메일·정책 문서의 기간 안내 문구가 실제 정책과 일치한다.
